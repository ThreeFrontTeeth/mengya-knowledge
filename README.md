# 萌芽知识库 · mengya-knowledge

一个用于学习、资料整理和内容创作的个人知识库。把零散想法和外部资料，逐步整理成有来源、能查证、可持续维护的知识。

**[进入知识库](萌芽知识库/首页.md)** · **[阅读 Wiki](萌芽知识库/06-Wiki/知识首页.md)** · **[查看工作流](萌芽知识库/05-Skills/知识库工作流.md)**

## 怎样使用

直接在 GitHub 阅读，或克隆到本地：

```bash
git clone https://github.com/ThreeFrontTeeth/mengya-knowledge.git
cd mengya-knowledge
```

从 `萌芽知识库/首页.md` 开始阅读。使用 Obsidian 时，可将内层 `萌芽知识库` 文件夹作为仓库打开。

使用 AI 编程工具协助整理时，先让工具读取内层的 [AGENTS.md](萌芽知识库/AGENTS.md) 和首页，再给出具体任务，例如：

- “把这份资料整理进知识库，优先更新已有主题，保留出处。”
- “根据知识库回答这个问题，并标明依据；需要时回到原始资料核对。”
- “检查重复内容、缺失来源和需要更新的地方，先给出修改建议。”

资料进入后，按需整理到已有主题；有价值的新理解经确认后写回；定期检查来源、链接和过期信息。当前仓库是 Markdown 内容与工作方法，不包含自动运行的后台整理服务。
