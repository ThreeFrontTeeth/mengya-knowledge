# 我的知识库

收进来的资料，在这里逐步变成能理解、能查证、能用于创作的知识。

## 今天想做什么

- 随口记一个想法 → [灵感随记](00-灵感库/灵感随记.md)
- 推进正在做的事情 → [进行中入口](01-进行中/进行中入口.md)
- 阅读完整作品和总结 → [成品入口](02-成品库/成品入口.md)
- 放入文章、播客、书本笔记或截图 → [资源说明](03-外部资源/资源说明.md)
- 阅读整理后的知识 → [知识首页](06-Wiki/知识首页.md)
- 使用可复用的方法 → [Skills 说明](05-Skills/使用说明.md)
- 查看历史过程和备份 → [历史记录说明](04-历史记录/历史记录说明.md)

## 按领域阅读

从 [知识首页](06-Wiki/知识首页.md) 进入与你当前问题相关的领域。领域随实际内容增加，可以覆盖学习、工作、兴趣和生活；不预设固定分类。具体方式见 [分领域管理](06-Wiki/分领域管理.md)。

## 直接这样使用

首次在已有文件夹中搭建时，使用 [搭建提示词与归类流程](05-Skills/知识库工作流.md#把当前文件夹搭建成知识库)。AI 先检查已有文章，提出归属和结构调整建议；无法确定是进行中、成品或其他用途的，再集中问你。保留当前顶层文件夹名称，按确认的范围整理。

“把这份资料整理进知识库，优先更新已有主题，保留出处。”

“根据知识库回答这个问题。”需要保存新理解时，再补一句“把有价值的内容补回相关知识页”。

“检查知识库，告诉我重复、缺失来源和需要更新的地方。”

操作细节由 AI 按 [工作流](05-Skills/知识库工作流.md) 与 [AGENTS.md](AGENTS.md) 处理。文件放进目录后仍需发起任务，不会自动开始整理。
